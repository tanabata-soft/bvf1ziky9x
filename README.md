# 命式シール（仮）試作版 v0.2.3

四柱推命アプリ『命式シール』の試作（プロトタイプ）。正本仕様は
`~/workspace/goals/goal-7/files/命式シール-仕様書.md`。

公開: https://tanabata-soft.github.io/bvf1ziky9x/ （gh-pages ブランチに dist を配置）

## できること（試作範囲）
- 入力（ニックネーム・生年月日・出生時刻／不明可、「保存する／今回だけ」）
- 命式計算（lunar-typescript の EightChar、節入り基準、23時台はライブラリ標準＝既定 sect）
- 読み表示（命式表・性格・五行バランス・今年と来年の運勢、運気6段階）
- 分身キャラ決定（形態5型、装備辞書、称号つき表示名）
- 英語プロンプト生成（部品の日本語併記、ネガティブプロンプト別枠）
- コレクション（localStorage、画像待ち→完成→贈った、シルエット仮表示）
- 画像登録→Canvasシール合成→書き出し（共有／ダウンロード）。書き出しは「シール単体」と「解説つき（シール＋性格ひとこと＋今年の運勢＋装備の意味）」の2形式（v0.1.3〜）
- レア度は仮ルール（チェックリスト方式）。シールには星を出さず、枠・ホロの派手さ3段階（ふつう／キラ／大当たり）で表す（v0.1.2〜）
- 表示名の基本形は「プレフィックス＋ニックネーム」。ポストフィックスは任意で、詳細画面で付け外しできる（v0.1.2〜）
- ボタンのフィードバック：押下で軽く沈むアニメーション、コピーは実際に書けたときだけ「コピーしました ✓」、書き出しは処理中〜完了表示（v0.1.4〜、prefers-reduced-motion で抑制）
- 呪文は正方形（1:1・全面）指定が先頭に入り、ネガティブにも横長・縦長の除外を追加。画像登録時は切り抜き調整（ドラッグ＋ズーム／ピンチ）で正方形の範囲を選べる。「全体を使う」では従来のはめ込み合成（v0.1.8〜）
- キャラの見た目は「指定なし／男の子／女の子」の3種。内部的には男の子＝イケメンアイドルのような顔立ち、女の子＝アイドルのような顔立ちとして呪文に反映する（v0.1.9〜。歌手系の装備・小物は入れず、顔立ちは少しリアル寄りで整った方向。人型・精霊型は本体表現を書き分け、他形態は顔まわりの小さな差のみ）。v0.1.8 の「イケメンアイドル」選択肢は男の子に統合し、保存済みの 'idol' は読み込み時に男の子として扱う
- v0.2.2: 実生成が「少年（子ども）」に見えたため、人型・精霊型の男の子・女の子は幼さを出す語（small／little）を外して「アイドルのような顔立ちの若者」に寄せ、顔立ちの描き込み（瞳の描き込み・鼻筋・口元・肌の自然な陰影）を強め、比率も約3頭身で少し大人びた指定に変更。あわせて、本文の slightly realistic と打ち消し合っていた単独 realistic を男女指定時のネガティブから外した（写真化・3D化の禁止 photorealistic／photograph／3d render は残す。指定なしは従来どおり）
- シール帳の一覧から、完成済みの登録は「解説つきで見る」でその場に解説つきシールを表示できる（全画面ビューア、共有／ダウンロードつき。生成は詳細画面の書き出しと共通処理。v0.1.9〜）
- 読み文面のバリエーション（v0.1.9〜）: 性格の書き出しは日干の要約に生まれ月の季節感と日支（相棒の動物）の一節を組み合わせ、今年の運勢本文には判定要素（支の合・冲・刑・三合、不足五行と流年の関係、最強の星）を反映した一文が入る。日干が同じ2人でも文面が分かれる
- 呪文とネガティブプロンプトに「共有」ボタン（v0.2.3〜）: OS の共有シートから Muse や Gemini などのアプリへ直接送れる。共有できない環境ではコピーにフォールバックする
- トーンは共通3種ではなく最強の通変ごとに固有の10種（v0.2.3〜）：正官＝ヒーロー（正統派）／正印＝賢者／正財＝守り手／食神＝癒し手／比肩＝一匹狼／劫財＝勝負師／傷官＝反逆者／偏財＝トリックスター／七殺＝ヴィラン／偏印＝幻惑者。選択制はやめ、命式から常に一意に自動決定する。旧版で手動選択した保存済み tone は読み込み時に使わない（データ自体は残す）。トーンごとに理由文・雰囲気文（EN/JA）・名前帯の色を持ち、称号は星ごとに1つ。「分身キャラの設計」に「トーン：名称 ― 最強の星『○○』は〜のため」と理由つきで表示する。ネガティブは影・闇系（比肩・劫財・傷官・偏財・七殺・偏印）で dark mood 禁止を外しホラー防止の語に替え、明るい系では維持する

## 呪文組み立て CLI（チャット用）
ニックネームと生年月日から、アプリと同一の計算で呪文を組み立てる。
```bash
node scripts/make-prompt.mjs ゆうと 1986-05-07 [--time HH:MM|unknown] [--appearance none|boy|girl]
```
表示名・形態・装備の要約と、英語プロンプト全文・ネガティブプロンプト全文を標準出力に出す。
トーンはアプリと同じく最強の通変から自動決定する。初回実行時に src の計算モジュールを
`scripts/.prompt-build/` へ変換する（ソースが新しいときだけ変換し直す）。

## 検証
- `npm test` : vitest 95件（計算層の単体テスト＋sxtwl突き合わせ12件＋切り抜き計算・正方形指定・見た目と顔立ち・解説文面のバリエーション・共有フォールバック・トーン固有10種の検証）
- sxtwl フィクスチャ生成: `scripts/gen_fixture.py`（要 Python + sxtwl）
  ※ sxtwl は日単位のため、節入りの時刻が絡む2件は日柱のみ突き合わせ、
  年柱・月柱は節気時刻ベースの期待値をテスト側に明記している
- `npm run build` : tsc + vite build
