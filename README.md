# 命式シール（仮）試作版 v0.2.10

四柱推命アプリ『命式シール』の試作（プロトタイプ）。正本仕様は
`~/workspace/goals/goal-7/files/命式シール-仕様書.md`。

公開: https://tanabata-soft.github.io/bvf1ziky9x/ （gh-pages ブランチに dist を配置）

## できること（試作範囲）
- 入力（ニックネーム・生年月日・出生時刻／不明可、「保存する／今回だけ」）
- 命式計算（lunar-typescript の EightChar、節入り基準、23時台はライブラリ標準＝既定 sect）
- 読み表示（命式表・性格・五行バランス・今年と来年の運勢、運気6段階）
- 分身キャラ決定（形態5型、装備辞書、称号つき表示名）
- 英語プロンプト生成（部品の日本語併記、ネガティブプロンプト別枠）
- コレクション（localStorage、画像待ち→完成→贈った、シルエット仮表示）
- 画像登録→Canvasシール合成→書き出し（共有／ダウンロード）。書き出しは「シール単体」と「解説つき（シール＋性格ひとこと＋今年の運勢＋装備の意味）」の2形式（v0.1.3〜）
- レア度は仮ルール（チェックリスト方式）。シールには星を出さず、枠・ホロの派手さ3段階（ふつう／キラ／大当たり）で表す（v0.1.2〜）
- 表示名の基本形は「プレフィックス＋ニックネーム」。ポストフィックスは任意で、詳細画面で付け外しできる（v0.1.2〜）
- ボタンのフィードバック：押下で軽く沈むアニメーション、コピーは実際に書けたときだけ「コピーしました ✓」、書き出しは処理中〜完了表示（v0.1.4〜、prefers-reduced-motion で抑制）
- 呪文は正方形（1:1・全面）指定が先頭に入り、ネガティブにも横長・縦長の除外を追加。画像登録時は切り抜き調整（ドラッグ＋ズーム／ピンチ）で正方形の範囲を選べる。「全体を使う」では従来のはめ込み合成（v0.1.8〜）
- キャラの見た目は「指定なし／男の子／女の子」の3種。内部的には男の子＝イケメンアイドルのような顔立ち、女の子＝アイドルのような顔立ちとして呪文に反映する（v0.1.9〜。歌手系の装備・小物は入れず、顔立ちは少しリアル寄りで整った方向。人型・精霊型は本体表現を書き分け、他形態は顔まわりの小さな差のみ）。v0.1.8 の「イケメンアイドル」選択肢は男の子に統合し、保存済みの 'idol' は読み込み時に男の子として扱う
- v0.2.2: 実生成が「少年（子ども）」に見えたため、人型・精霊型の男の子・女の子は幼さを出す語（small／little）を外して「アイドルのような顔立ちの若者」に寄せ、顔立ちの描き込み（瞳の描き込み・鼻筋・口元・肌の自然な陰影）を強め、比率も約3頭身で少し大人びた指定に変更。あわせて、本文の slightly realistic と打ち消し合っていた単独 realistic を男女指定時のネガティブから外した（写真化・3D化の禁止 photorealistic／photograph／3d render は残す。指定なしは従来どおり）
- シール帳の一覧から、完成済みの登録は「解説つきで見る」でその場に解説つきシールを表示できる（全画面ビューア、共有／ダウンロードつき。生成は詳細画面の書き出しと共通処理。v0.1.9〜）
- 読み文面のバリエーション（v0.1.9〜）: 性格の書き出しは日干の要約に生まれ月の季節感と日支（相棒の動物）の一節を組み合わせ、今年の運勢本文には判定要素（支の合・冲・刑・三合、不足五行と流年の関係、最強の星）を反映した一文が入る。日干が同じ2人でも文面が分かれる
- 呪文とネガティブプロンプトに「共有」ボタン（v0.2.3〜）: OS の共有シートから Muse や Gemini などのアプリへ直接送れる。共有できない環境ではコピーにフォールバックする
- 職業（旧称トーン）は「RPG の職業」10種（v0.2.4 で正式化）：正官＝騎士／正印＝僧侶／正財＝商人／食神＝吟遊詩人／比肩＝武闘家／劫財＝闘士／傷官＝魔法使い／偏財＝盗賊／七殺＝暗黒騎士／偏印＝占い師。選択制はやめ（v0.2.3〜）、命式から常に一意に自動決定する。旧版で手動選択した保存済み tone は読み込み時に使わない（データ自体は残す）。職業ごとに理由文・雰囲気／装い文（EN/JA）・名前帯の色を持ち、称号は星ごとに1つ（職業と地続き）。呪文の装いは装備ルールを最優先し、矛盾しない範囲の雰囲気づけに留める。「分身キャラの設計」に「職業：名称 ― 最強の星『○○』は〜のため」と理由つきで表示し、解説つきシールにも職業の項目を入れる（シール単体には入れない）。ネガティブは影・闇系（武闘家・闘士・魔法使い・盗賊・暗黒騎士・占い師）で dark mood 禁止を外しホラー防止の語に替え、明るい系（騎士・僧侶・商人・吟遊詩人）では維持する
- 年齢区分（v0.2.5〜）：男の子・女の子の見た目では、生年月日から生成時点の年齢で決まる5区分（〜12 子ども／13〜19 若者／20〜39 青年／40〜59 中年／60〜 円熟）に応じて年齢感（顔立ちと比率）を変える。若者は v0.2.4 の表現そのまま、子どもは約2.5頭身、青年・中年・円熟は約3.5頭身。中年は老けさせすぎず、円熟は貫禄と穏やかさで表し老いは強調しない（髪に少し銀色が混じる程度は可）。指定なし・他形態の比率は従来どおり。判定は fortune.ts の ageBandOf（純粋関数）で、アプリと CLI が共用する
- 体格と髪（v0.2.5〜）：体格・全体の雰囲気はいちばん強い五行（木＝すらりと伸びやか／火＝華やかで明るい存在感／土＝穏やかでどっしり／金＝シャープで凛々しい／水＝柔らかく神秘的）から、髪の色・髪型は日干の五行（木＝緑がかった茶／火＝赤み／土＝落ち着いた茶／金＝銀に近い明るい色／水＝黒から深い青）から自動で決まる。人型・精霊型は体格と髪として、獣型は毛並みの色合い、道具型・群体型は差し色として弱く反映する。髪色は年齢区分によらず五行どおり
- 外見の理由の説明（v0.2.5〜）：「分身キャラの設計」に年齢感・体格・髪の理由つき行（「年齢の区分（○歳〜）から」「いちばん強い五行『○』の性質から」「日干『○』（五行）の性質から」）を追加し、解説つきシールにも「見た目」の節を新設（explainedInfoOf の appearanceLines、詳細画面と一覧ビューアで共通）。シール単体には入れない
- 顔の装飾（v0.2.6〜）：職業ごとに顔・頭の装飾を1つ割り当て、呪文に1文として入れる（騎士＝サーカレットとバイザーを上げた小さな兜／僧侶＝薄いベール／商人＝ターバン風の巻き布／吟遊詩人＝羽根つき帽子／武闘家＝鉢巻／闘士＝額当てのヘッドギア／魔法使い＝とんがり帽子／盗賊＝口元マスクとフード／暗黒騎士＝黒いハーフマスク／占い師＝透けるベールとフード）。利用者は選べない。頭にサブ装備が乗る命式では装備の置き場所を優先し、装飾は小さい版に弱める。覆うのは顔の半分程度までを上限とし、表現は「半分程度は見える」側で書く（フルフェイスは使わない）。口元を覆うマスクの職業では人型・精霊型の顔立ち文を目元中心の文に差し替え、透けるベールは表情が読めるため顔立ち文はそのまま。顔まわりの装い（羽根帽子・とんがり帽子・フード）は雰囲気文から装飾へ一本化した。部品併記・「分身キャラの設計」・解説つきシール「見た目」の節にも「顔の装飾：〜 ― 職業『○○』から」と理由つきで出す
- イケオジ風（v0.2.7〜、オーナー指示）：男の子の中年・円熟は「イケオジ風」にする。実生成で白い長いヒゲの老人寄りになった指摘への対応で、スタイリッシュで洗練された魅力的な大人の男性（身だしなみが整い、凛々しく、余裕のある笑顔と自信）として描き、「老け」とは切り分ける。ヒゲは付けない形を基本にし（短く整えたヒゲは身だしなみとして許容）、長いヒゲ・白いヒゲはネガティブでも禁止する。円熟の髪の銀色はシルバーフォックスの魅力として活かす（白髪だらけにはしない）。女の子・青年以下・指定なしは変更なし。なお「イケオジ風」という説明は外見の理由文には出さない（v0.2.9、オーナー指示）
- 職業の装い（v0.2.8〜、オーナー指示「せっかく職業があるので職業を強調して」）：職業ごとに装い（衣装）を明確に定義し、呪文で "dressed unmistakably as a ..." と強く打ち出す（騎士＝磨かれた軽い鎧風の装いとマント／僧侶＝穏やかな法衣とストール／商人＝豪華なベストと懐中時計のチェーン／吟遊詩人＝色鮮やかな旅の演奏家の衣装と短いケープ／武闘家＝道着風の装いと巻いた帯／闘士＝グラディエーター風の軽装鎧／魔法使い＝星と月の刺繍のローブ／盗賊＝身軽な装いと短い旅マント／暗黒騎士＝黒い鎧風の装い／占い師＝月と星の模様の神秘的なローブ）。装備ルールが最優先で、装いは装備の置き場所を奪わない。職業の小道具は背中の1つまで（吟遊詩人のリュートのみ）で、サブ装備が腰・頭まで埋まっている命式では小さなチャームに弱める。顔の装飾と重なる要素（魔法使いの帽子、占い師のベール等）は装飾側に一本化する。「分身キャラの設計」と解説つきシールの職業の行にも装いを短く添える（シール単体には入れない）
- 「見た目」の説明の整理（v0.2.10〜、オーナー指示）：外見の理由文に出すのは命式由来の根拠だけにし、作り手都合の注記（装備の優先順位や、小さい版にした理由など）は出さない。あわせて「見た目」の節（分身キャラの設計・解説つきシール・CLI の外見の理由）から年齢感の行と顔の装飾の行を削除し、体格・髪の2行にした。年齢区分や顔の装飾の呪文への反映はどちらも維持する

## 呪文組み立て CLI（チャット用）
ニックネームと生年月日から、アプリと同一の計算で呪文を組み立てる。
```bash
node scripts/make-prompt.mjs ゆうと 1986-05-07 [--time HH:MM|unknown] [--appearance none|boy|girl]
```
表示名・形態・装備の要約と、英語プロンプト全文・ネガティブプロンプト全文を標準出力に出す。
職業はアプリと同じく最強の通変から自動決定し、装い・年齢区分・体格・髪・顔の装飾とその理由（外見の理由）も要約に出す。初回実行時に src の計算モジュールを
`scripts/.prompt-build/` へ変換する（ソースが新しいときだけ変換し直す）。

## 検証
- `npm test` : vitest 157件（計算層の単体テスト＋sxtwl突き合わせ12件＋切り抜き計算・正方形指定・見た目と顔立ち・年齢区分の境界と文言・体格と髪・外見の理由・解説文面のバリエーション・共有フォールバック・職業10種の検証・顔の装飾の割り当てと覆い方・イケオジ風の出し分け・職業の装いの打ち出しと小道具の優先）
- sxtwl フィクスチャ生成: `scripts/gen_fixture.py`（要 Python + sxtwl）
  ※ sxtwl は日単位のため、節入りの時刻が絡む2件は日柱のみ突き合わせ、
  年柱・月柱は節気時刻ベースの期待値をテスト側に明記している
- `npm run build` : tsc + vite build
